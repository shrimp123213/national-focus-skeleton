# 分期國策 UI 樣品

> 此頁是先前另做的獨立介面，未符合「目前腳本加上分期」的要求。最新樣品請看[現有腳本分期樣品](period-preview/README.md)；本機 4186 預覽入口已改為提供新版。以下保留舊樣品說明。

這是獨立的互動 HTML 樣品，不連接 API、不讀寫 MVU，也不改動正式國策腳本。重新整理頁面會重設演示。內容改編自《樣稿-分期承接與世界變局.md》；正常完成情境的下一期 11 項新國策，為本次 UI 展示補寫。

## 開啟

直接以瀏覽器開啟同目錄的 `分期國策-UI樣品.html` 即可，沒有外部字型、圖片或腳本依賴。

也可以在 PowerShell 啟動僅提供此頁面的本機伺服器：

```powershell
& 'C:\Program Files\nodejs\node.exe' 'F:\命一串\national-focus-skeleton\docs\preview-periods.mjs'
```

開啟 <http://127.0.0.1:4186/>。終端按 Ctrl+C 停止。此伺服器只綁定本機，不提供專案目錄列表或其他檔案。

## 可操作內容

- 國策圖可拖曳、滾輪縮放、雙指縮放，或使用加減與全覽按鈕。鍵盤 Tab 可選節點，方向鍵移動畫布。
- 點擊國策查看內容、狀態、完成成果與前置／互斥條件。這個樣品不執行新國策選擇或完整國策計時。
- 頂端棕色列是演示工具，不是正式產品中的「手動換期」功能。可選局勢突變或議程完成，再按「推進局勢」觀察結果。
- 右側可切換國策詳情、持續事件與往期摘要。窄畫面改為底部資訊面板，點擊國策、往期或閱覽事件開啟，可按 × 或 Escape 收起。
- 換期開關關閉時，推進局勢只更新事件，原樹保持不變。再次開啟後，下一次演示更新才換期。
- 往期只顯示時間與摘要；「重看第一期」會重設整個演示，不是完整歷史樹瀏覽。

## 樣品範圍

每期畫面均為 12 項，第二期包含 1 項承接與 11 項新增。災害情境的承接國策保留 18／30 日，議程完成情境保留終點的已完成狀態；後續演示更新只推進事件文字，不推進故事日或自動發放成果。穩定度與戰爭支持度是固定示意數值。

手機初次顯示以選中的承接／進行中國策為中心，保留可讀字級；「全覽」才縮小到整棵樹。樣品採用「承接國策不是所有新議程的必要前置」的待定建議，未藉此替正式規格定案。

## 人工驗收

狀態：**待人工驗收**。未使用 computer use 或瀏覽器自動化驗收 UI。

1. 桌面開啟，拖曳與滾輪縮放，點擊不同節點；確認節點、連線同步移動，詳情正確，拖曳放開不會誤開國策。
2. 選「局勢突變」，按「推進局勢」。確認進入〈災厄越過國境〉，承接節點顯示 18／30 日；往期只有時間與摘要。
3. 再推進事件，確認〈渡鴉港的船位之爭〉仍是同一件事，新增進展但沒有第二份歷史摘要。
4. 重看第一期，關閉自動換期後推進局勢。確認原樹仍在，快訊與事件已更新；開啟後再次推進才換期。
5. 選「議程完成」，確認未選互斥路線仍可點閱。推進後以已完成的〈北境貿易新秩序〉承接，不重啟進度；舊債事件繼續。
6. 窄視窗或手機測試拖曳、雙指縮放、全覽，以及底部詳情／往期面板的開啟與收起。檢查頂端演示控制沒有溢出。
7. 鍵盤 Tab 選取圖外節點時，畫布應將該節點帶入視野；Enter 開啟詳情，資訊頁籤可用左右鍵切換。
