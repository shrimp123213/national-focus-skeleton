# 國策檔案介面打磨樣品

以 v0.14.4 的正式 `mountUI`、DemoPlatform、分期邏輯及報紙卡片為基礎。只在樣品中附加 CSS 與比較工具，沒有修改 src、dist 或正式版本號。示範文案與國家識別色是設計提案，不代表新增世界書設定。

## 開啟

直接開啟 `F:\命一串\national-focus-skeleton\docs\國策檔案-介面打磨樣品.html`。所有程式與樣式已內嵌，不依賴伺服器或 CDN，也不連接酒館與 API。

可從專案目錄執行 `node docs/polish-preview/serve.mjs`，網址為 http://127.0.0.1:4186/。重新建置執行 `node docs/polish-preview/build.mjs`。

## 比較與人工驗收

- 頂部切換「現行版／打磨版」：使用同一份示範狀態，只切換附加視覺樣式；兩者都為比較工具保留頂部空間。
- 切換帝國、北境與蒼海：查看配色、紋章框形、議程、主國策與路線的辨識度。
- 拖曳、縮放、搜尋、定位與開啟節點詳情：沿用正式介面。留意更大文字是否溢出，以及詳情是否遮住必要操作。
- 「測試操作 › 推進事件／演示換期」：沿用正式分期示範；檢查期名、承接國策與往期摘要。載入其他分期情境或重設會沿用既有示範的資料重置行為。
- 切換報紙：第一次開啟時建立獨立示範資料，此後保留閱讀狀態。可比較排版、改變字級、切換深淺色、展開與收合。這是閱讀樣品，沒有接上 MVU 或主面板的即時資料同步。
- 請在桌面與手機寬度檢查頂部工具、國家狀態、期別列、畫布與詳情。建議寬度 1440、1024、390px；特別留意小螢幕可用畫布高度。
